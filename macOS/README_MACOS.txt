Android Explorer - macOS Installer
====================================

Double-click:
    Install Android Explorer.command

Installs:
    /Applications/Android Explorer.app

The installer handles both Apple Silicon and Intel Macs through Homebrew.

Dependencies installed automatically:
- Python 3.13
- Android Platform Tools (adb)
- scrcpy
- PySide6-Essentials inside the app bundle

The installed app appears normally in /Applications and uses the bundled
blue-folder icon.

Note:
macOS may require Control-click > Open the first time because this installer
is not Apple code-signed/notarized.
